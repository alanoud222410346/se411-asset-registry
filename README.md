# Computer Asset Registry

SE411 project (Fall 2026-27), Part 1: React frontend.

A web app to manage the computers of a company. You can view, add, edit and delete computers. Data is stored in memory only.

## Setup

You need Node.js (LTS) installed.

```
npm install
npm run dev
```

Then open the address shown in the terminal (usually http://localhost:5173).

## Run the tests

```
npm run test
```
